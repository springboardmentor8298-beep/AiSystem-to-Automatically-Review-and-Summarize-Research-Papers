# AI-Powered Systematic Review Generator

## Features
- 🔍 Automated paper search via Semantic Scholar API
- 📄 PDF text extraction and section segmentation
- 🤖 GPT-based draft generation for abstracts, methods, and results
- 📊 Cross-paper analysis and theme identification
- 📚 APA 7th edition reference formatting
- 🎨 Modern Gradio web interface
- 🚀 FastAPI backend for programmatic access
